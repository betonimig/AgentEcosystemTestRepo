# Partnership Agent Ecosystem

> A collection of AI agents, skills, prompts, and MCP tools for working with the Exness Partnership platform.

Build AI-powered workflows that can explore partnership data, investigate issues, generate reports, and automate everyday operations through the Model Context Protocol.

## What’s Inside

| Component | Description |
| --- | --- |
| 🔌 **MCP Server** | Connects AI assistants to the Partnership API |
| 🤖 **Agents** | Ready-to-use assistants for common business workflows |
| 🧩 **Skills** | Reusable instructions for specialized tasks |
| 💬 **Prompts** | Practical prompt examples for users and developers |
| 🔐 **OAuth** | Secure authentication with OAuth 2.1 and PKCE |
| 📚 **OpenAPI Tools** | Automatically generated tools from the API schema |
